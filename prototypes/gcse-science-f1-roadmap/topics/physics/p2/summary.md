# Speed, distance and time

Speed is the rate at which distance is travelled.

`average speed = total distance / total time`

In SI units, distance is in metres, time is in seconds and speed is in metres per second, `m/s`.
Convert values to compatible units before substitution.
The relationship can be rearranged to `distance = speed x time` or `time = distance / speed`.

Average speed describes a whole interval.
Instantaneous speed is the speed at one moment.
A speedometer reading is an instantaneous speed, while total distance divided by total journey time gives average speed.
Average speed is not necessarily the maximum speed or the arithmetic mean of two speeds.

## Distance-time graphs

Time is on the horizontal axis and distance is on the vertical axis.
The gradient represents speed:

`speed = change in distance / change in time`

- A steeper line means a greater speed.
- A straight sloping line means constant speed.
- A horizontal line means the object is stationary.
- A changing gradient means the speed is changing.

Graph height shows distance reached, not speed.
Include gradient units, such as `m/s`.
A distance-time graph cannot slope down because total distance travelled does not decrease.
This differs from a signed position-time graph, which can decrease when position changes in the negative direction.
