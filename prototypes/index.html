Prototypes

Small self-contained HTML prototypes published as static GitHub Pages files.

Mind Map Viewer Markdown outline rendered as a pannable, zoomable mind map. Modern LLM Timelines Model development and inference stages as an explorable timeline. Jump Rope Interval Timer Work/break interval timer with round tracking. Browser LLM Chat Chat with a small LLM running entirely in-browser via WebGPU. Meeting Cost Meter Live £-burn meter for meetings, by headcount and hourly rate. Context Kit Assemble, tag, and reorder prompt context for AI coding sessions. AI Coding Playbook Checklist of AI coding practices with progress tracking. Voice Kit In-browser speech-to-text and text-to-speech, local models only. Noise Nudge Live room-loudness meter that counts distracting peaks. GCSE Triple Science: F1 Roadmap GCSE science syllabus as a prerequisite graph, linked to Formula 1. Day Mosaic Daily activity log rendered as a Mondrian-style mosaic grid. FogLAMP Scan Viewer Codebase scan JSON rendered as a local Cytoscape graph. Mortgage Compass Visualises mortgage interest vs. ownership, and buying vs. renting. Scorecard Tally Sums handwritten score grids and flags mismatches instantly. UK Income Tax and NI Visualiser Salary split across Income Tax and National Insurance bands, marginal rate shown. Card Vision Test In-browser vision model reads a Symbiosis card from a photo; logs accuracy.
