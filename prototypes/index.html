Prototypes

Small self-contained HTML prototypes published as static GitHub Pages files.

Mind Map Viewer Renders a Markdown outline as a mind map with real touch pan and pinch zoom, keeps a local library of maps, and documents the format. Modern LLM Timelines Navigate model development and inference serving stages, inspect cross-cutting work, and expand notes sourced from YAML. Jump Rope Interval Timer Alternates work and break timers, tracks completed rounds, and keeps controls large for mobile use. Browser LLM Chat Loads a small WebGPU model in the browser and provides a simple chat surface with streaming replies. Meeting Cost Meter Turns attendee count and hourly rate into a live money burn meter for ending low-value meetings faster. Context Kit Assemble and manage prompt context for AI coding sessions: paste snippets, estimate tokens, tag by intent, drag to reorder. AI Coding Playbook Checklist of actionable AI coding practices extracted from today HN discussions, with progress tracking and export. Voice Kit In-browser speech-to-text (Whisper) and text-to-speech (Kitten TTS). Both models run locally via WebGPU or WASM. Noise Nudge Uses the microphone locally to show live room loudness and count distracting peaks over a threshold. GCSE Triple Science: F1 Roadmap Models the triple science syllabus as a prerequisite graph, links every topic to how it shows up in Formula 1 and in the workshop, and tracks progress locally with JSON export and import. Day Mosaic Logs your day as manually-switched activity blocks and renders them as a Mondrian-style mosaic grid, zoomable to day, week, or month. FogLAMP Scan Viewer Local Cytoscape map of a codebase scan JSON, plus a Prompt tab to copy the fixed agent instruction for the next run. Mortgage Compass Explains how a mortgage splits into interest and ownership, shows the impact of overpaying, and compares buying with renting across three prototype views. Scorecard Tally Type in each player's 4x2 grid of handwritten scores and their circled total; it sums and flags mismatches instantly, entirely offline.
