## Probability

Probability measures chance on a scale from `0` for an impossible event to `1` for a certain event.
When outcomes are equally likely, divide the number of favourable outcomes by the total number of possible outcomes.

For combined events, list outcomes systematically or use a tree diagram so that no possible route is missed.
Multiplying probabilities gives the probability of both events only when the relevant conditional probabilities have been identified; for independent events, one event does not change the probability of the other.

Probability can support a decision by comparing possible outcomes, but the calculation is only as sound as the assumptions behind it.
Never assume that events are independent unless the information given justifies it.
