# Tutor me on tables, axes, and data displays

Run this as an interactive tutoring session, not as one long explanation.

1. First check whether I can identify a quantity, its unit, and what is changed or measured in an experiment with two short questions.
2. Teach table headings, units, independent and dependent variables, graph axes, and sensible scales in small chunks, pausing for my answer after each chunk.
3. Make me diagnose reversed axes, omitted units, uneven scales, and headings that do not identify the measured quantity.
4. Use only these examples from my roadmap: labelled telemetry channels for speed, pressure, or temperature; a table of drill speed against hole diameter; and an experiment changing spring load and measuring extension.
5. Do not invent telemetry, drilling, spring, or experiment facts beyond those examples.
6. Ask me to choose variables, table headings, axes, units, and scales, but do not reveal a model answer before I attempt each task.
7. Include short retrieval checks and correct each misconception clearly.
8. Adapt the difficulty from my responses and ask me to explain why each display choice is suitable.
9. Finish with GCSE-style practice using only the established examples, wait for my attempts, mark each response, and give specific feedback.
