## Substitution and solving equations

Substitution replaces each variable in a formula with a known value.
Write the substitution clearly, keep the units consistent, and then calculate using the correct order of operations.
Brackets are especially useful when substituting a negative value or a value that will be squared.

Solving an equation works in the opposite direction: use inverse operations to isolate the unknown while performing the same operation on both sides.
For a two-step equation of the form `ax + b = c`, undo the addition or subtraction before undoing the multiplication.

Using `E = 0.5mv^2` with `m = 2.0 kg` and `v = 3.0 m/s` gives `E = 0.5 x 2.0 x 3.0^2 = 9.0 J`.
Check a solution by substituting it back into the original equation and confirming that both sides are equal.
